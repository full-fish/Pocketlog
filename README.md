# Pocketlog

카드 문자·알림은 자동으로, 문자가 안 오는 결제(쿠팡머니 등)는 스크린샷 한 장으로 채워지는 Android 가계부. 기획은 [기획서.md](기획서.md). [개인정보처리방침](PRIVACY.md) · [서비스 약관](TERMS.md).

- **자동 기록:** 카드·은행·페이 알림과 문자를 읽어 바로 적어요. 같은 결제가 두 번 와도 한 번만 적고, 취소되면 지워요.
- **스크린샷:** 알림이 없는 결제는 주문내역 스크린샷을 공유하면 AI가 주문과 품목, 카테고리, 태그까지 나눠 적어요.
- **나에게 들어오고 나가는 돈만:** 내 계좌끼리 옮긴 돈, 카드값, 페이머니 충전은 적지 않아요. 저축·투자는 지출이 아니라 따로 모아요.
- **카테고리 1개 + 태그 여러 개:** "식비 #외식 #야식 #친구·모임"처럼 적고, 분석에서 태그별로도 봐요.

---

## 사용 흐름

### 1. 처음 켜기

소개 3장 → **알림 접근 허용**(카드 문자 자동 기록) → **내 이름과 한 달 시작일** 순서예요.

- 내 이름(통장에 찍히는 실명): 은행 알림에 받는 사람·보낸 사람이 내 이름이면 내 계좌끼리 옮긴 돈이라 적지 않아요.
- 한 달 시작일: 월급날 기준으로 한 달을 나눠요(예: 25일 ~ 다음 달 24일). 홈·내역·분석·예산이 모두 이 기준을 써요.
- 결제수단은 카드 문자가 처음 올 때 카드사·끝 4자리로 자동으로 만들어져요.
- 직접 설치한 앱은 알림 접근을 켤 때 "제한된 설정" 창이 떠요. 휴대폰 설정 → 애플리케이션 → Pocketlog → ⋮ → **제한된 설정 허용** 후 다시 켜요.

### 2. 결제하면: 자동 기록

카드·은행·페이 앱의 알림과 문자 알림이 오면 아래 순서로 처리해요.

1. **결제 알림인지 확인:** 금액(원)과 승인·결제·출금·입금 같은 단어, 카드사·은행 이름이 있어야 해요. 광고와 개인 메시지는 저장하지 않아요.
2. **같은 문구가 10분 안에 또 오면** 무시해요.
3. **막을 조건**(설정 → 자동 기록, 키워드·금액)에 걸리면 무시해요.
4. **문구 읽기:** 앱 안의 규칙으로 금액·가맹점·할부·시각·카드사·카드 끝 4자리를 읽어요. 가맹점을 못 찾으면 AI가 읽어요(AI 사용 동의를 켰을 때만). 그래도 못 읽으면 **확인 필요**로 남겨요.
5. **적지 않는 돈 거르기:**
   - 카드 가승인·선승인(택시 등): 실제 요금은 따로 승인돼요.
   - 받는 사람·보낸 사람이 내 이름인 이체, 카드값 출금, 페이머니 충전(교통카드 충전은 교통비로 적어요).
   - 내 은행 계좌끼리 옮긴 돈: 출금과 입금 알림이 5분 안에 같은 금액으로 오면 둘 다 지워요.
6. **저축·투자:** 출금·입금 문구에 적금·청약·예금·증권·펀드·연금저축 같은 말이 있으면 저축(넣으면 +, 빼면 −)으로 적어요. 증권·투자·펀드·주식·연금이면 "투자", 아니면 "저축"이고 문구에 든 태그 이름(적금, 청약 …)을 붙여요.
7. **중복:** 같은 금액이 3분 안에, 같은 결제수단·비슷한 가맹점으로 이미 있으면(문자 + 카드 앱 알림) 한 번만 적어요.
8. **해외 결제:** 원화 없이 외화만 오면 그날 환율로 바꿔 바로 적고, 메모에 환율을 남겨요(카드사 청구액과 조금 다를 수 있어요).
9. **취소:** 31일 안의 같은 금액(해외 결제는 같은 외화 금액)·가맹점 결제를 "취소됨"으로 바꿔요. 원래 결제가 없거나 부분 취소면 마이너스 금액으로 적어 지출을 줄여요(수입이 아니에요).
10. **할부:** 3개월이면 매달 1건씩 3건으로 나눠 적어요. 첫 달에 나머지 금액이 붙어요.
11. **카테고리·태그 고르기:** 아래 "자동 분류"대로 해요.
12. **저장 알림:** "김밥천국 8,000원 · 식비로 기록했어요"처럼 알려요(설정에서 끌 수 있어요). 예산의 50%·80%·100%를 넘으면 기간마다 한 번씩 알려요.
13. **놓친 알림 다시 읽기:** 휴대폰이 앱을 잠재운 사이 온 알림은 앱을 열 때 알림창에 남아 있는 것을 다시 읽어요. 같은 앱이 다른 문구로 보낸 같은 금액은 별개 결제로 적어요(뽑기 1,000원 두 번). 첫 실행 때 배터리 사용 "제한 없음"을 요청해요.

### 3. 문자가 안 오는 결제: 스크린샷 · 영수증

1. 쇼핑·배달·페이 앱의 주문내역을 캡처해 **Pocketlog로 공유**하거나, 입력 화면 위의 **사진**으로 골라요. 종이 영수증은 **촬영**으로 바로 찍어요. 여러 장도 돼요.
2. 긴 스크린샷은 1:2 비율로 10%씩 겹치게 잘라(최대 8장) AI에 보내요. 작은 글씨를 잘 읽도록 크기는 줄이지 않아요(긴 변 2576px까지).
3. 분석은 뒤에서 계속되고(5~20초), 끝나면 알림이 와요. 같은 스크린샷을 다시 보내면 지문(해시)으로 알아보고 "이미 저장한 스크린샷"이라고 보여 줘요.
4. **검토 화면:** 주문마다 날짜·가맹점·금액·결제수단, 품목마다 "카테고리 #태그"를 보여 줘요.
   - 카드 문자로 이미 적힌 결제와 같아 보이면: **품목만 붙이기**(기본) / 따로 저장 / 건너뛰기.
   - 품목 합계가 결제 금액과 다르거나 글씨가 흐리면 경고를 보여 줘요. 금액을 눌러 고칠 수 있어요.
   - 결제수단이 화면에 없으면, 그 앱에서 지난번에 고른 결제수단을 기본으로 골라요.
   - "품목별로 따로 저장"을 켜면 품목마다 내역 1건, 끄면 주문 1건으로 저장하고 통계는 품목별 카테고리로 나눠요.
5. 저장하면 이미지는 상세 화면에 쓸 썸네일(긴 변 960px, 장당 약 0.1MB)로 줄여 남겨요. 저장하지 않은 분석은 30일 뒤, 내역을 지운 스크린샷은 다음에 앱을 켤 때 이미지를 지워요. 같은 스크린샷인지는 이미지가 아니라 지문(해시)으로 알아봐서 그대로 돼요.

### 4. 직접 입력

\+ 버튼 → 지출 / 수입 / 저축 → 금액(계산기 키패드) → 가맹점(자동완성) → 카테고리 → 태그 → 결제수단 → 날짜·시간 → 할부 → 메모.

- 가맹점을 치면 그 가맹점의 **마지막 내역**의 카테고리와 태그를 먼저 골라 줘요. 처음 보는 곳이면 아래 ①②로 골라요.
- 태그는 두 줄로 나와요. 위는 고른 카테고리의 태그, 아래는 **공통 태그**예요. 줄 끝 **+ 태그**로 바로 추가할 수 있어요.
- 카테고리나 태그를 내가 고르면 그 가맹점의 규칙으로 기억해요.
- **외화:** 금액 아래 **원화 ▾**에서 USD·JPY·EUR 등을 고르면 외화로 입력하고(키패드 마지막 키가 소수점), 그날 환율로 원화가 바로 계산돼요. 내역에는 원화로 저장되고 상세에 외화 금액이 남아요.
- **즐겨찾기:** 가맹점 칸 옆 **즐겨찾기**를 누르면 같은 시트가 즐겨찾기 목록으로 바뀌어요(반복 기록은 안 나와요). 정렬 옆 **+**로 같은 시트에서 새 즐겨찾기를 만들고, 저장하면 목록으로 돌아와요. 하나를 누르면 금액·가맹점·카테고리·태그·결제수단이 한 번에 채워져요. 이름 검색, 정렬(사용자 정의 · 이름 오름/내림 · 최신 · 오래된 순, 마지막 선택을 기억), 사용자 정의 순서에서는 길게 눌러 끌어 순서를 바꿔요.
- **반복 기록:** 설정 → 즐겨찾기 · 반복 기록의 **반복 기록** 탭에서 **+ 추가**(직접 입력과 같은 창, "매월 O일 ▾" 칩으로 매주 O요일 / 매월 O일)로 만들면 그날 오전 9시에 알아서 적어요(출처 "반복"). 즐겨찾기와는 따로 관리해요. 폰이 꺼져 있어 놓친 날은 나중에 그 날짜로 채워요.

### 5. 카테고리·태그 자동 분류

순서는 **① 내 규칙 → ② 가맹점 사전 → ③ AI**예요. 앞에서 답이 나오면 뒤로 가지 않아요.

| 단계 | 무엇 | 비교 방법 | 결과 |
|---|---|---|---|
| ① 규칙 | 내가 직접 고른 것, AI가 고른 것, 똑똑가계부에서 가져온 것 | 띄어쓰기·(주)·대소문자를 빼고, 가맹점 이름 안에 규칙 글자가 들어 있으면 맞음. 여러 개면 **가장 긴 규칙**(쿠팡이츠 > 쿠팡) | 카테고리 + 그 카테고리의 태그 |
| ② 사전 | 앱에 들어 있는 브랜드·키워드 약 40줄 (씨유·GS25 → 카페·간식 #편의점 등) | 위에서부터 처음 맞는 줄 | 기본 카테고리 이름일 때만 |
| ③ AI | 처음 보는 **지출** 가맹점 (AI 사용 동의를 켰을 때만) | 가맹점 이름 한 줄 + 지출 카테고리·태그 목록만 보냄 | 카테고리 + 태그, **규칙으로 저장**해서 다음엔 안 물어봄 |

- **지점:** "스타벅스 김포점"을 고치면 지점 이름을 뗀 "스타벅스"로 저장해서 다른 지점도 맞아요. "스타벅스김포점"처럼 붙어 있으면 브랜드가 어디까지인지 몰라 그대로 저장해요.
- **예외:** "스타벅스" 규칙이 있는데 한 지점만 다르게 고치면 그 지점만 예외 규칙이 생겨요. 규칙이 이미 같은 답을 주면 새로 저장하지 않아요.
- **공통 태그는 기억하지 않아요:** 데이트·친구·모임·가족·회식·여행·업무·청구·나는 그때그때의 상황이라, 규칙에도 AI에도 넣지 않아요.
- **수입:** ①②로 고르고, 모르면 "용돈·기타"예요(AI 안 씀). 저축은 위 6번 규칙을 따라요.
- **스크린샷:** 품목마다 AI가 카테고리와 태그를 고르고, ①의 규칙 30개를 힌트로 같이 보내요.
- 규칙은 설정 → 카드 문자·알림 자동 기록 → **카테고리 규칙**에서 보고 지울 수 있어요.

### 6. 확인 필요

자동 기록 중 확실하지 않은 것(가맹점을 못 읽음, 해외 결제라 원화 금액이 없음, 문구를 못 읽음)은 홈의 **확인이 필요한 내역**에 모여요. 직접 고치거나, 상세 화면의 **AI로 다시 읽기**를 눌러요(AI 사용 동의를 켰을 때).

### 7. 보기

- **홈:** 이번 달 쓴 돈 · 수입 · 저축 · 남은 돈(수입 − 지출 − 저축), 이번 주 · 이번 달 · 올해 예산과 오늘 써도 되는 금액, 확인 필요, 분석 중인 스크린샷, 가장 많이 쓴 곳, 최근 내역.
- **내역:**
  - 월 이동(버튼·좌우로 밀기·연월 고르기), 일별 합계, 전체/지출/수입/저축 필터, 카테고리·결제수단으로 보기, 달력.
  - 검색(가맹점·메모·카테고리·결제수단·금액).
  - 밀어서 삭제(되돌리기)·복제, 길게 눌러 여러 건 선택 → 카테고리 바꾸기·삭제.
  - 상세: 원문 문자, 품목, 스크린샷 썸네일, 태그.
- **분석:**
  - 지출 · 수입 · 저축 · 합산 × 주·월·분기·년·전체·기간 지정.
  - 분류 차트: 카테고리별 · 태그별 · 결제수단별 · 요일별 · 시간대별 · 내역별.
    - **태그별**은 태그마다 따로 더해요. "외식"과 "야식"이 둘 다 붙은 내역은 양쪽에 들어가서 비율을 다 더하면 100%가 넘을 수 있어요.
  - 기간 차트: "지출 전체 ▾"에서 카테고리를 고르고, 옆 "태그 전체 ▾"에서 그 카테고리의 태그 하나만 고를 수 있어요. 노란 점선은 평균, 빨간 점선은 그 기간 단위(주·월·연)의 예산이에요(전체 또는 카테고리 예산이 있을 때). 예산 통일을 켜면 분기·기간 지정 차트에도 월 예산에서 나눈 예산선이 나와요.
  - 패턴: 요일 × 시간대 히트맵, 평일·주말 하루 평균, 자주 가는 곳 Top 10(지점은 브랜드로 묶음).
  - **월간 리포트**(위 "리포트"): 한 달 시작일 오전 9시에 지난달 리포트가 알림으로 와요. 앱이 계산한 숫자로 AI가 요약, 눈에 띈 것 3가지, 예산, 다음 달에 해 볼 것, 잘한 점을 쓰고, 화면에는 같은 숫자로 그린 그래프가 함께 나와요: 이번 달·지난달 막대, 날마다 쓴 돈, 카테고리 도넛과 지난달 비교, 태그, 자주 간 곳, 평일·주말, 큰 지출 5개, 예산 막대.
  - 아래 표와 차트 조각을 누르면 그 내역 목록이 나와요.
- **자산:** 이번 주 · 이번 달 · 올해 예산(전체와 카테고리별), 결제수단별 사용액, 알고 있는 잔액 합계.
  - 예산 편집의 **주 · 월 · 연 통일**을 켜면 하나만 정해도 나머지가 맞춰져요(1년 = 12달 = 52주, 100원 단위). 기간마다 **보이기**를 끄면 홈·자산과 예산 알림에서 빠져요.
- **위젯:** 홈 화면에 "이번 달 쓴 돈 + 남은 예산"을 두고, 월 예산이 있으면 쓴 비율 막대와 "지금쯤이어야 할 위치" 선을 그려요(한 달의 반이 지났으면 가운데). 크기에 맞춰 내용이 늘어요: 1줄은 금액과 막대, 2줄은 예산·속도 설명과 남은 금액, 3줄 이상은 오늘 쓴 돈과 많이 쓴 카테고리 3개, 더 크면 최근 내역 4건까지. 가로로 넓히면 + 입력 · 촬영 · 사진 버튼이 붙어요. 앱 잠금을 켜면 금액을 숨겨요.

### 8. 설정

- **기본:** 카테고리 편집, 결제수단 편집, 한 달 시작일, 한 주 시작 요일, 화면 테마, 예산(주·월·연), 즐겨찾기 · 반복 기록.
- **카테고리 편집:** 지출·수입·저축 탭이 있어요. 카테고리는 길게 눌러 순서를 바꾸고, 태그는 다른 카테고리나 공통 태그로 끌어 옮겨요. 이름·아이콘(75개)·색, 숨기기, 합치기, 삭제가 있어요.
- **자동 기록:** 배터리 사용 제한 없음, 켜기/끄기, 저장 알림, 카테고리 자동 분류, 내 이름, 막을 조건, 쇼핑 앱별 기본 결제수단, 카테고리 규칙.
- **AI:** 사용 동의(처음엔 꺼짐), 모델 고르기, 월간 리포트 켜기·지난 리포트.
- **보안·데이터:** 앱 잠금(PIN 6자리 + 지문·얼굴), 백업·복구·초기화.
  - **백업 파일 만들기:** 비밀번호로 암호화한 파일이에요.
  - **백업 파일에서 복구:** 암호화 백업이나 Pocketlog `.db` 파일을 골라요.
  - **Google 드라이브에 백업 / 복구:** 같은 암호화 파일을 내 드라이브의 **Pocketlog 폴더**에 올리고 골라서 되돌려요. 최근 5개만 남기고 오래된 것부터 지워요. 처음 한 번 Google 계정을 고르고, 앱은 자기가 올린 파일만 볼 수 있어요(`drive.file`).
  - **매일 자동 백업(기본 켜짐):** 직접 한 번 드라이브에 백업하면 그 비밀번호를 폰 보안 저장소(Android Keystore)로 암호화해 두고, 하루 한 번(오전 9시 작업 또는 앱을 켤 때) 알아서 올려요.
  - **똑똑가계부에서 가져오기:** 백업 `.db`에서 지출·수입·카테고리(하위 카테고리는 태그로)·결제수단·할부를 옮기고, 과거 기록으로 가맹점 규칙을 만들어요.
- **테스트(개발용 빌드에만):** 더미 데이터 넣기·지우기(진짜 내역은 그대로). 넣을 때마다 전의 더미를 지우고 27번 표대로 5년치 내역, 해외 결제 6건, 즐겨찾기 9개(반복 4개)를 새로 만들어요.

## 카테고리와 태그

기본값은 [Db.kt](app/src/main/java/com/choimanseon/pocketlog/data/Db.kt)의 `defaultSeeds`예요.

| 종류 | 카테고리 (태그) |
|---|---|
| 지출 | 식비 (외식 · 장보기 · 야식), 카페·간식 (커피 · 디저트·빵 · 과자·간식 · 편의점), 술·유흥, 쇼핑, 생활, 주거·통신, 교통·차량, 건강·의료, 뷰티·미용, 문화·여가, 구독, 교육, 경조사·선물, 금융, 기타, 반려동물·육아(숨김) |
| 공통 태그 | 데이트 · 친구·모임 · 가족 · 회식 · 여행 · 업무·청구 · 나 (어느 지출 카테고리에서나) |
| 수입 | 급여 (월급 · 상여 · 수당), 부수입, 금융수입, 용돈·기타 |
| 저축 | 저축 (적금 · 예금 · 청약 · 비상금), 투자 (주식 · ETF·펀드 · 연금 · 코인) |

- 내역 하나에는 **카테고리 1개**와 **태그 여러 개**가 붙어요. 태그는 그 카테고리의 태그와 공통 태그 중에서 골라요.
- 저축은 지출도 수입도 아니에요. 넣으면 +, 빼면 −이고 **남은 돈 = 수입 − 지출 − 저축**이에요.

## AI

API 키는 앱에 넣지 않고 Cloudflare Worker([server/](server/README.md))에 둬요. 앱은 Worker만 불러요.

| 언제 | 보내는 것 | 경로 |
|---|---|---|
| 스크린샷을 공유했을 때 | 스크린샷(긴 변 2576px까지), 지출 카테고리·태그 목록, 내 규칙 30개 | `/scan` |
| 앱이 알림 문구를 못 읽었을 때 | 이름·카드번호·잔액을 가린 문구 | `/parse` |
| 처음 보는 지출 가맹점 | 가맹점 이름, 지출 카테고리·태그 목록 | `/categorize` |
| 한 달 시작일 오전 9시 | 지난달 집계 숫자(카테고리·태그·가맹점별 합계, 예산, 패턴). 내역 원문·이름·카드번호는 안 보냄 | `/report` (항상 GPT-6 Astra, 약 80원) |

- 알림을 AI에 보내는 건 **설정 → AI → AI 사용 동의**를 켰을 때만이에요. 스크린샷은 내가 직접 공유할 때만 보내요. 서버는 저장하지 않아요.
- 모델은 설정 → AI 모델에서 골라요. 가짜 데이터로 잰 값이에요(2026-10-05, 1달러 = 1,400원):

| 모델 | 스샷 1장 | 가맹점 분류 1번 | 스샷 걸린 시간 |
|---|---|---|---|
| GPT-6 Luna (기본) | 약 1원 | 약 0.1원 | 약 7초 |
| GPT-6.1 Sol | 약 19원 | 약 3원 | 약 13초 |
| GPT-5.5 | 약 50원 | 약 7원 | 약 6초 |
| GPT-6 Astra | 약 90원 | 약 13원 | 약 9초 |

- 네 모델 모두 품목·금액·카테고리·태그를 맞혔어요. 이미지를 줄여도 걸리는 시간은 같고 Luna에선 0.2원만 줄어서, 작은 글씨를 잘 읽도록 원래 크기로 보내요(768px까지 줄이면 잘못 읽기 시작해요).

## 내 폰에서 실행

1. 폰에서 개발자 옵션 → USB 디버깅(또는 무선 디버깅)을 켜고 연결
2. 설치

```bash
./gradlew installDebug
```

연결 없이 설치하려면 `./gradlew assembleDebug`로 만든 `app/build/outputs/apk/debug/app-debug.apk`를 폰에 옮겨 열면 돼요.

3. 앱 정보 → ⋮ → **제한된 설정 허용** (직접 설치한 앱은 이걸 해야 알림 접근을 켤 수 있음)
4. 앱 홈의 "카드 문자 자동 기록 켜기" → Pocketlog 알림 접근 허용

디버그 빌드도 패키지 이름이 `com.choimanseon.pocketlog`예요(혼자 쓰는 앱이라 개발용을 따로 두지 않아요). 나중에 릴리스 빌드를 만들면 서명이 달라서 이 앱 위에 바로 깔리지 않아요. 백업 → 지우기 → 설치 → 복구 순서로 옮겨요.

### AI 켜기

[server/README.md](server/README.md)대로 Worker를 배포한 뒤 `local.properties`에 주소와 토큰을 적고 다시 빌드하세요. 그 전에는 AI만 안 되고 나머지는 모두 동작해요. **APK 안에 토큰이 들어가니** 디버그 APK를 남에게 주지 마세요.

### Google 드라이브 백업 켜기

Google Cloud에 이 앱을 한 번 등록해야 해요. 앱에 넣을 키는 없어요(패키지 이름과 서명으로 알아봐요).

1. Google Cloud 콘솔에서 프로젝트를 만들고 **Google Drive API**를 사용 설정
2. OAuth 동의 화면: 대상 "외부", 범위에 `https://www.googleapis.com/auth/drive.file`. **대상 → 앱 게시(프로덕션)** 를 눌러 두면 7일마다 다시 허용할 필요가 없어요. `drive.file`은 민감하지 않은 범위라 Google 심사가 없어요
3. 클라이언트 만들기 → **Android**: 패키지 `com.choimanseon.pocketlog`, SHA-1은 아래 명령의 값

```bash
keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android | grep SHA1
```

등록 전에 버튼을 누르면 "Google 드라이브에 연결하지 못했어요 (10)"이 떠요.

## 테스트

```bash
./gradlew testDebugUnitTest
```

- `CardParserTest`: 카드사·은행·페이 문자 파싱. **실제 문자가 잘못 읽히면 그 문자를 케이스로 추가하고 고치면 돼요.**
- `AutoInputTest`: 알림 → 내역 저장 전체 흐름(중복, 취소, 적지 않는 돈, 저축, 규칙·태그, 차단 규칙).
- `DomainTest`: 기간, 추이 막대, 계산기, 품목·태그별 통계, 분석 ↔ 내역 목록 일치, 카테고리·태그 끌어 옮기기.
- `MigrationTest`: DB 이전(하위 카테고리 → 태그, 저축 분리).
- `ClevImportTest`: 똑똑가계부 가져오기(`CLEV_DB=백업경로`를 주면 실제 백업으로도 확인).
- `DummyTest`: 5년치 더미 데이터 넣기·지우기, 태그가 표대로 붙는지.
- `RepeatTest`: 반복 기록 날짜(말일·요일)와 놓친 날 채우기.
- `ReportTest`: 월간 리포트에 보내는 숫자. `REPORT_FACTS_OUT=파일`을 주면 더미 데이터의 지난달 숫자를 파일로 써요(지시문 확인용).
- `ScreenshotTest`: 샘플 데이터로 실제 화면을 그려 `app/build/screenshots/`에 PNG로 저장(에뮬레이터 없이 화면 확인용).
