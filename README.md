# Pocketlog

카드 문자·알림은 자동으로, 문자가 안 오는 결제(쿠팡머니 등)는 스크린샷 한 장으로 채워지는 Android 가계부. 기획은 [기획서.md](기획서.md).

## 내 폰에서 실행

1. 폰에서 개발자 옵션 → USB 디버깅을 켜고 USB로 연결
2. 설치

```bash
./gradlew installDebug
```

3. 앱 정보 → ⋮ → **제한된 설정 허용** (직접 설치한 앱은 이걸 해야 알림 접근을 켤 수 있음)
4. 앱 홈의 "카드 문자 자동 기록 켜기" → Pocketlog 알림 접근 허용

디버그 빌드는 `com.choimanseon.pocketlog.dev`로 설치돼서 나중에 스토어 버전과 같이 깔 수 있어요.

## AI(스크린샷 분석) 켜기

API 키는 앱에 넣지 않고 Cloudflare Worker에 둡니다. [server/README.md](server/README.md)대로 배포한 뒤 `local.properties`에 주소와 토큰을 적고 다시 빌드하세요. 설정 전에는 스크린샷 분석만 안 되고 나머지는 모두 동작해요.

## 구조

```
app/src/main/java/com/choimanseon/pocketlog/
  data/      Room 엔티티·DAO·기본 카테고리
  domain/    기간(월급날 기준 월), 금액 계산기, 통계 집계
  auto/      카드 문자·알림 파서, 자동입력 판정(중복·취소·이체), 카테고리 분류, 알림 리스너
  ai/        AI 프록시 호출, 스크린샷 분할·분석·저장
  ui/        Compose 화면 (홈·내역·분석·자산·입력·상세·스샷 검토·설정·잠금)
  Security.kt  PIN 해시, 암호화 백업
server/      Cloudflare Worker (OpenAI 호출)
```

## 테스트

```bash
./gradlew testDebugUnitTest
```

- `CardParserTest`: 카드사·은행·페이 문자 15종 파싱. **실제 문자가 잘못 읽히면 여기에 그 문자를 케이스로 추가하고 고치면 됩니다.**
- `AutoInputTest`: 알림 → 내역 저장 전체 흐름 (중복, 취소, 기록하지 않는 돈: 내 계좌 간 이체·카드값·페이머니 충전·택시 선승인, 개인 메시지 무시, 차단 규칙)
- `DomainTest`: 월급날 기준 기간, 계산기, 품목 분할 통계
- `ScreenshotTest`: 샘플 데이터로 실제 화면을 그려 `app/build/screenshots/`에 PNG로 저장 (에뮬레이터 없이 화면 확인용)

## 구현 현황 (기획서 P0 = MVP)

완료
- 직접 입력: 금액 계산 키패드, 가맹점 자동완성, 카테고리 대/소분류, 결제수단, 할부(매달 1건씩 나눠 저장), 날짜·시간, 메모
- 첫 실행 안내: 소개 3장, 알림 접근, 내 이름·한 달 시작일, 똑똑가계부 가져오기
- 글꼴: Pretendard (가변 폰트, OFL 라이선스는 `assets/licenses`)
- 내역: 월 이동(버튼·좌우로 밀기), 일별 그룹·합계, 지출/수입/이체 필터, 달력(일별 지출 강도), 검색, 스와이프 삭제(되돌리기)·복제, 길게 눌러 여러 건 선택 → 카테고리 일괄 변경·삭제, 상세(원문·품목)
- 자동 기록: 카드·은행·페이 앱 알림과 문자 알림, 결제수단 자동 생성, 중복·취소 판정, 차단 규칙, 저장 알림, 확인 필요함. **나에게 들어오고 나가는 돈만 기록**하고, 내 계좌 간 이체(설정의 "내 이름"으로 판단)·카드값 출금·페이머니 충전·카드 선승인은 기록하지 않음
- AI 스크린샷: 공유하기·사진 선택, 긴 스크린샷 분할, 주문·품목 추출, 기존 내역(카드 문자)과 중복 감지·품목 붙이기, 쇼핑 앱별 기본 결제수단 학습
- 카테고리 자동 분류: 내 규칙 → 가맹점 사전 → AI(처음 보는 가맹점만, 결과는 규칙으로 저장)
- 홈(이번 달 요약, 예산, 지난달 대비), 분석(카테고리 도넛, 6개월 막대+예산선), 자산(기간별 예산·결제수단 사용액·잔액)
- 설정: 카테고리·결제수단 편집, 월 시작일·주 시작 요일, 테마(다크 모드), 앱 잠금(PIN 6자리+생체), 암호화 백업·복구, 초기화
- 똑똑가계부 가져오기: 백업 .db 파일에서 지출·수입·카테고리·결제수단을 그대로 옮기고(달마다 나눠 저장된 할부 포함), 과거 기록으로 "가맹점 → 카테고리" 규칙을 만들어요. 실제 백업으로 8,537건과 연도별 합계가 원래 앱과 같은지 확인함 (`CLEV_DB=백업경로 ./gradlew testDebugUnitTest --tests '*ClevImportTest*'`)

아직 안 됨
- 실제 폰에서의 확인: 알림 리스너(삼성 메시지·카드 앱), 생체인증, 백업 파일, 공유하기는 기기에서 아직 안 돌려 봤어요
- AI 서버 배포: OpenAI 키로 로컬 Worker를 띄워 분류·문자 해석·스크린샷 분석을 실제로 호출해 봤어요. Cloudflare 배포(`npx wrangler login` 필요)는 아직이에요
